# V0.4.5 - 统一 playerId 体系（一账户一角色）

> **目标**：简化玩家体系，采用一账户一角色设计，统一使用 `playerId`
> **完成时间**：2026-05-06

---

## 架构概述

```
┌─────────────────────────────────────────────────────────────┐
│                      一账户一角色设计                          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  accountId = playerId （合二为一）                            │
│                                                              │
│  ┌──────────┐      ┌──────────┐      ┌──────────┐         │
│  │  Account │  =   │  Player  │  =   │ playerId │         │
│  └──────────┘      └──────────┘      └──────────┘         │
│                                                              │
│  优势：                                                       │
│  • 无需 selectRole 接口                                       │
│  • 无需 roleId 概念                                          │
│  • Login 后直接返回角色信息                                   │
└─────────────────────────────────────────────────────────────┘
```

---

## 数据存储

| 存储层 | 数据类型 | 说明 |
|--------|----------|------|
| **MySQL** | 账号、角色基础信息 | accounts 表 |
| **内存** | 在线玩家完整数据 | LobbyServer Session |
| **内存** | 场景位置数据 | SceneServer PlayerManager |

> **注意**：位置信息（pos_x, pos_y, pos_z, scene_id）由 SceneServer 运行时管理，不存储在 MySQL

## 数据库表结构

### accounts 表

```sql
CREATE TABLE accounts (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,    -- playerId = accountId
    username VARCHAR(64) NOT NULL UNIQUE,   -- 用户名
    password VARCHAR(128) NOT NULL,          -- 密码
    player_name VARCHAR(64) DEFAULT '',      -- 角色名
    job INT DEFAULT 0,                       -- 职业
    level INT DEFAULT 1,                    -- 等级
    exp BIGINT DEFAULT 0,                   -- 经验
    hp INT DEFAULT 100,                     -- 血量
    max_hp INT DEFAULT 100,                  -- 最大血量
    mp INT DEFAULT 50,                       -- 魔法
    max_mp INT DEFAULT 50,                   -- 最大魔法
    create_time BIGINT DEFAULT 0,            -- 创建时间
    last_login_time BIGINT DEFAULT 0,        -- 最后登录
    INDEX idx_username (username)
);
```

### player_online 表

```sql
CREATE TABLE player_online (
    player_id BIGINT PRIMARY KEY,            -- 玩家ID
    server_id INT DEFAULT 0,                 -- 服务器ID
    scene_id INT DEFAULT 0,                  -- 场景ID
    online_time BIGINT DEFAULT 0             -- 上线时间
);
```

## 接口设计

### DBServant (DBServer)

```tars
interface DBServant
{
    // 账号操作
    int createAccount(string username, string password, out long accountId);
    int getAccountByName(string username, out AccountInfo account);
    int getAccountById(long accountId, out AccountInfo account);
    int accountExists(string username, out bool exists);
    int updateAccount(AccountInfo account);

    // 角色操作
    int initCharacter(long accountId, string playerName, int job, out AccountInfo character);
    int getCharacter(long playerId, out AccountInfo character);
    int updateCharacter(AccountInfo character);
};
```

### LobbyServant (LobbyServer)

```tars
interface LobbyServant
{
    int login(LoginReq req, out LoginRsp rsp);
    int registerAccount(RegisterReq req, out RegisterRsp rsp);
    int createCharacter(CreateCharacterReq req, out CreateCharacterRsp rsp);
    int heartbeat(HeartBeatReq req);
    int enterScene(EnterSceneReq req, out EnterSceneRsp rsp);
    int move(MoveReq req, out MoveRsp rsp);
    int leaveScene(LeaveSceneReq req, out LeaveSceneRsp rsp);
    int registerPush(long playerId);
};
```

## 客户端流程

```
┌─────────────────────────────────────────────────────────┐
│                   登录流程                                │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  1. registerAccount → 注册账号                           │
│         ↓                                                │
│  2. login → 登录（返回 hasCharacter）                   │
│         ↓                                                │
│  3. [hasCharacter = false]                              │
│     → createCharacter → 创建角色                         │
│         ↓                                                │
│  4. enterScene → 进入游戏                                │
│         ↓                                                │
│  5. heartbeat (每 3s) → 保活                            │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## Session 管理

```cpp
struct PlayerSession {
    long playerId;              // = accountId
    long sessionKey;            // = 登录时间戳
    long lastHeartbeat;         // 最后心跳时间
    bool isOnline;              // 是否在线
    int sceneId;                // 所在场景
};
```

| 操作 | 说明 |
|------|------|
| createSession | Login 成功后立即创建 |
| validateSession | 验证 sessionKey |
| updateHeartbeat | 更新心跳，检测重连 |
| removeSession | 30s 无心跳后清除 |

---

## 心跳机制

| 参数 | 值 | 说明 |
|------|-----|------|
| 心跳间隔 | 3s | 客户端发送频率 |
| 超时检测 | 5s | 服务端扫描间隔 |
| 超时判定 | 15s | 无心跳判定离线 |
| Session 清理 | 30s | 离线后清除 |
