## 快速开始

### 从 V0.1 开始

```bash
# 1. 创建协议文件
mkdir -p tars
vim tars/Scene.tars

# 2. 创建 SceneServer
cd /workspace/server
/usr/local/tars/cpp/script/cmake_tars_server.sh SceneServer SceneServer Scene

# 3. 编译发布
cd SceneServer/build
cmake .. && make -j4
make SceneServer-tar
make SceneServer-upload

# 4. 启动客户端测试
cd /workspace/client/GameClient/build
./GameClient
```

## 版本回退策略

如果某个版本遇到无法解决的问题：
1. 记录问题现象和复现步骤
2. 回退到上一个稳定版本
3. 分析问题根因
4. 在下一个迭代中修复
