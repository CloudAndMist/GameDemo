# V0.3 - 移动同步增强

> **目标**: 优化移动同步性能，实现 AOI 九宫格算法
>
> **完成时间**: 2026-05-04

## 架构概述

V0.3 将玩家数据和 AOI 索引合并到统一的 `PlayerManager` 中管理：

```
SceneServer (全局单例，Application 级别)
    └── PlayerManager _playerManager  ← 全局唯一，供所有 Imp 实例共享
            ├── _players (玩家数据 map)
            ├── _grids (AOI 九宫格索引)
            └── _rwlock (单一读写锁)

SceneImp (每个请求一个实例)
    └── 缓存 PlayerManager 指针 _playerMgr
```

**为什么 PlayerManager 在 SceneServer 层而不是 SceneImp 层**：
- Tars 框架中 `SceneImp` 是按请求实例化的，多个线程会各自创建独立的 `SceneImp`
- 如果 `_playerManager` 在 `SceneImp` 中，每个线程会有独立的数据，导致数据不共享
- 将 `PlayerManager` 放在 `SceneServer` 层，作为全局单例，所有 Imp 线程共享同一份数据

## 核心功能

1. **AOI 九宫格** - 视野管理，减少无效广播
2. **移动节流** - 限制移动请求频率
3. **批量推送** - 合并推送减少网络开销
4. **增量同步** - 进出视野增量通知

## AOI 九宫格算法

### 算法说明

```
    ┌──────────┬────────┬─────────┐
    │     1    │   2    │    3    │     场景被划分为网格
    │  M-1,N-1 │  M,N1  │  M+1,N-1│     每个格子为固定大小
    ├──────────┼────────┼─────────┤     玩家视野 = 3x3 或 5x5 九宫格
    │     4    │   5    │    6    │
    │  M-1,N   │  M,N   │  M+1,N  │     玩家进入/离开/移动时
    ├──────────┼────────┼─────────┤     检查视野内格子是否有玩家变化
    │     7    │   8    │    9    │     有变化则通知视野内玩家
    │  M-1,N+1 │  M,N+1 │  M+1,N+1│
    └──────────┴────────┴─────────┘
```

### 视野计算

```
    ┌─────┬─────┬─────┐
    │  1  │  2  │  3  │
    ├─────┼─────┼─────┤
    │  4  │ [5] │  6  │    [5] = 当前玩家所在格子
    ├─────┼─────┼─────┤    服务端推送 = 玩家视野 = 3×3 九宫格
    │  7  │  8  │  9  │
    └─────┴─────┴─────┘
```

**AOI_GRID_SIZE vs AOI_VIEW_RANGE 的关系**：
- `AOI_GRID_SIZE`：每个格子的大小（如 10×10 米）
- `AOI_VIEW_RANGE`：玩家视野范围，同时也是服务端推送范围（如 30 米）
- 计算：视野范围决定九宫格半径 = `AOI_VIEW_RANGE / AOI_GRID_SIZE` = 3 格（单边）
- 视野内格子数 = 3×3 = 9 个格子

## 服务端与客户端职责

```
服务端 (SceneServer)
├── 维护地图格子数据
├── 计算玩家九宫格邻居
├── 推送视野内玩家变化 → 客户端

客户端 (Client)
├── 接收服务端推送
├── 渲染推送列表中的玩家（服务端已过滤，无需二次判断）
└── 本地不做视野计算
```

## 数据结构

### PlayerManager 对外接口

| 接口 | 内部操作 | 说明 |
|------|----------|------|
| `playerEnter()` | 添加数据 + 加入格子 | 玩家进入场景 |
| `playerMove()` | 更新数据 + 更新格子 | 玩家移动 |
| `playerLeave()` | 离开格子 + 移除数据 | 玩家离开场景 |
| `getViewPlayers()` | 计算九宫格邻居 | 获取视野内玩家 |

### Session 结构

```cpp
struct PlayerSession {
    long playerId;           // 玩家ID
    long sessionKey;         // 简化 Token = 登录时间戳
    int sceneId;             // 所在场景 (-1表示不在场景中)
    int64_t offlineTime;     // 断线时间（0表示在线）
    int64_t lastHeartbeat;   // 最后心跳时间
    bool isOnline;           // 是否在线
};
```

## 配置参数

```tars
AOI_GRID_SIZE = 10.0       // 格子大小(米)，地图被划分成网格
AOI_VIEW_RANGE = 30.0      // 视野范围(米)，同时也是服务端推送范围
MOVE_FREQUENCY_LIMIT = 10  // 每秒最多移动10次
BROADCAST_INTERVAL = 50    // 批量广播间隔(ms)
```

**设计原则**：玩家视野 = 服务端九宫格推送范围，简化实现。
