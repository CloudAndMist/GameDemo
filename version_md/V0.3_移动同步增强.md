# V0.3 - 移动同步增强

> **目标**: 优化移动同步性能，实现 AOI 九宫格算法

## 完成时间
- 预计: 3-4 天

## 功能特性

### 核心功能
1. **AOI 九宫格** - 视野管理，减少无效广播
2. **移动节流** - 限制移动请求频率
3. **批量推送** - 合并推送减少网络开销
4. **增量同步** - 进出视野增量通知

### 性能目标
| 指标 | 目标值 |
|------|--------|
| 单服同时在线 | 500+ |
| 移动同步延迟 | < 100ms |
| 广播消息量 | 减少 70% |

## 技术方案

### AOI 九宫格算法

```
    ┌──────────┬────────┬─────────┐
    │     1    │   2    │    3    │     场景被划分为网格
    │  M-1,N-1 │  M,N1  │  M+1,N-1│     每个格子为固定大小
    ├──────────┼────────┼─────────┤     玩家视野 = 3x3 或 5x5 九宫格
    │     4    │   5    │    6    │
    │  M-1,N   │  M,N   │  M+1,N  │     玩家进入/离开/移动时
    ├──────────┼────────┼─────────┤     检查视野内格子是否有玩家变化
    │     7    │   8    │    9    │     有变化则通知视野内玩家
    │  M-1,N+1 │  M,N+1 │  M+1,N+1│
    └──────────┴────────┴─────────┘
```

### 配置参数说明

```tars
// 配置文件
AOI_GRID_SIZE = 10.0       // 格子大小(米)，地图被划分成网格
AOI_VIEW_RANGE = 30.0      // 视野范围(米)，同时也是服务端推送范围
MOVE_FREQUENCY_LIMIT = 10  // 每秒最多移动10次
BROADCAST_INTERVAL = 50    // 批量广播间隔(ms)
```

**设计原则**：玩家视野 = 服务端九宫格推送范围，简化实现。

**AOI_GRID_SIZE vs AOI_VIEW_RANGE 的关系**：
- `AOI_GRID_SIZE`：每个格子的大小（如 10×10 米）
- `AOI_VIEW_RANGE`：玩家视野范围，同时也是服务端推送范围（如 30 米）
- 计算：视野范围决定九宫格半径 = `AOI_VIEW_RANGE / AOI_GRID_SIZE` = 3 格（单边）
- 视野内格子数 = 3×3 = 9 个格子

```
    ┌─────┬─────┬─────┐
    │  1  │  2  │  3  │
    ├─────┼─────┼─────┤
    │  4  │ [5] │  6  │    [5] = 当前玩家所在格子
    ├─────┼─────┼─────┤    服务端推送 = 玩家视野 = 3×3 九宫格
    │  7  │  8  │  9  │
    └─────┴─────┴─────┘
```

**服务端与客户端职责**：
```
服务端 (SceneServer)
├── 维护地图格子数据
├── 计算玩家九宫格邻居
├── 推送视野内玩家变化 → 客户端

客户端 (Client)
├── 接收服务端推送
├── 渲染推送列表中的玩家（服务端已过滤，无需二次判断）
└── 本地不做视野计算
```

**格子内移动 vs 跨格子移动**：
- **格子内移动**：位置变化但仍在同一格子内 → **仍需同步**给视野内玩家（只是位置更新）
- **跨格子移动**：离开当前格子 → **重新计算视野玩家**（可能有人进入/离开视野）

## 实现步骤

### Step 1: AOI 模块设计
```cpp
// AOIManager.h
class AOIManager {
public:
    // 初始化场景网格
    void init(int sceneWidth, int sceneHeight, float gridSize);
    
    // 进入场景
    void enter(Player* player);
    
    // 离开场景
    void leave(Player* player);
    
    // 移动
    void move(Player* player, float newX, float newY);
    
    // 获取视野内玩家
    vector<Player*> getViewPlayers(Player* player);
    
    // 获取改变的玩家(进入/离开)
    pair<vector<Player*>, vector<long>> getChangedPlayers(Player* player);
    
private:
    // 坐标转格子
    pair<int, int> posToGrid(float x, float y);
    
    // 格子坐标转格子ID
    int gridToId(int gx, int gy);
    
    // 九宫格邻居
    vector<int> getNeighborGrids(int gx, int gy, int range = 1);
    
private:
    float _gridSize;
    int _gridXCount;
    int _gridYCount;
    
    // 格子ID -> 玩家列表
    unordered_map<int, unordered_set<long>> _grids;
    
    // 玩家ID -> 玩家对象
    unordered_map<long, Player*> _players;
};
```
