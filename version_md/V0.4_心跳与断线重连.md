# V0.4 - 心跳与断线重连

> **目标**: 实现完整的断线重连机制，保障玩家体验
>
> **完成时间**: 2026-05-05

## 架构概述

采用**心跳超时自动检测 + 客户端被动重连**机制：

- 客户端每 3s 发送心跳，不等待响应
- LobbyServer 每 5s 扫描所有 Session，超 15s 无心跳判定超时
- 客户端心跳恢复时，服务端自动检测并通知 SceneServer 恢复在线状态
- 无需显式 reconnect 接口，客户端只需恢复心跳发送即可重连

## 架构原则

```
┌──────────────────────────────────────────────────────────┐
│                     客户端                                │
│                     心跳 ──────────────────────────────────→ LobbyServer
└──────────────────────────────────────────────────────────┘

                         ┌───────────────────────────────────┘
                         ▼
              ┌─────────────────┐
              │  LobbyServer    │
              │  心跳管理        │
              │  • Session 管理  │
              │  • 超时检测      │
              │  • 状态保存      │
              └─────────────────┘
                         │
          ┌──────────────┴──────────────┐
          ▼                             ▼
   玩家主动离开                    超时触发离线
   leaveScene()                   notifyPlayerOffline()
          │                             │
          ▼                             ▼
┌─────────────────────────────────────────────────────────┐
│                    SceneServer                          │
│  • 接收 LobbyServer 的离线通知                           │
│  • 清理玩家 AOI 数据和对象内存                           │
└─────────────────────────────────────────────────────────┘
```

### 数据存储架构

LobbyServer 使用两个 map 管理数据：

```
┌─────────────────────────────────────────────────────────────┐
│                    LobbyServer                              │
├─────────────────────────────────────────────────────────────┤
│  _sessions[playerId]          _playerCurrents[playerId]     │
│  ├── sessionKey (登录时间戳)   └── TarsCurrentPtr            │
│  ├── lastHeartbeat                (用于服务端推送)           │
│  ├── isOnline                                              │
│  ├── offlineTime                                           │
│  └── sceneId                                               │
│                                                             │
│  位置信息 (x, y, z) 存储在 SceneServer，不在 LobbyServer    │
└─────────────────────────────────────────────────────────────┘
```

## 技术方案

### 心跳超时检测流程

```
客户端 ──[heartbeat RPC 3s]──▶ LobbyServer (单向调用，无响应)
                                   │
                                   ▼
                            更新 lastHeartbeat
                                   │
                                   ▼
                     ┌─────────────────────────┐
                     │  HeartbeatThread         │ (每 5s 执行)
                     │  checkHeartbeatTimeout() │
                     └────────────┬────────────┘
                                  │
               ┌──────────────────┴──────────────────┐
               ▼                                       ▼
         lastHeartbeat < now-15                  lastHeartbeat >= now-15
               │                                       │
               ▼                                       ▼
        playerOffline()                           无操作
        (标记离线，通知 SceneServer)
               │
               ▼
        15s-30s 内重连? ──[是，心跳恢复]──▶ playerOnline()
        (自动通知 SceneServer)              (标记在线，通知 SceneServer)
               │
               ▼ (否)
        30s 后清除 Session
        (彻底清理数据)
```

### 断线重连完整流程

```
┌─────────┐                    ┌─────────────┐                      ┌─────────────┐
│ Client  │                    │ LobbyServer │                      │ SceneServer │
└────┬────┘                    └──────┬──────┘                      └──────┬──────┘
     │                                │                                    │
     │   1. 登录 (login)              │                                    │
     │───────────────────────────────▶│  创建 Session                      │
     │   ← 返回 sessionKey            │                                    │
     │                                │                                    │
     │   2. selectRole                │                                    │
     │───────────────────────────────▶│                                    │
     │   (自动启动心跳)                │                                    │
     │                                │                                    │
     │   3. enterScene                │                                    │
     │───────────────────────────────▶│───────────────────────────────────▶│
     │                                │                                    │
     │   4. 心跳保活 (每 3s)           │                                    │
     │───────────────────────────────▶│  更新 lastHeartbeat                │
     │                                │                                    │
     │   ✕ 5. 断线                    │                                    │
     │   (心跳停止)                   │                                    │
     │     ✕                           │                                    │
     │                                │                                    │
     │                                │   6. 15s 后判定超时               │
     │                                │   → playerOffline()               │
     │                                │───────────────────────────────────▶│
     │                                │                                    │
     │                                │   7. 通知周围玩家 (onPlayerOffline)│
     │◀───────────────────────────────│                                    │
     │   8. 显示掉线状态              │                                    │
     │                                │                                    │
     │   9. 重连 (恢复心跳发送)        │                                    │
     │───────────────────────────────▶│                                    │
     │                                │   10. updateHeartbeat 检测到重连   │
     │                                │   → playerOnline()               │
     │                                │───────────────────────────────────▶│
     │                                │                                    │
     │                                │   11. 通知周围玩家 (onPlayerOnline)│
     │◀───────────────────────────────│                                    │
     │   12. 显示在线状态              │                                    │
     │                                │                                    │
     │                                │   13. 30s 后清除 Session           │
     │                                │   (如玩家未重连)                  │
     │                                │                                    │
```

> **注意**: V0.4 客户端不需要显式调用 reconnect 接口，只需恢复心跳发送即可自动重连。

## Session 结构

```cpp
struct PlayerSession {
    long playerId;           // 玩家ID
    long sessionKey;         // 简化 Token = 登录时间戳
    int sceneId;             // 所在场景 (-1表示不在场景中)
    int64_t offlineTime;     // 断线时间（0表示在线）
    int64_t lastHeartbeat;   // 最后心跳时间
    bool isOnline;           // 是否在线
};
```

## Tars 接口定义

### LoginRsp（修改）

```tars
struct LoginRsp
{
    0 require int ret;
    1 optional string msg;
    2 optional long accountId;
    3 optional long playerId;
    4 optional string qqNumber;
    5 optional long sessionKey;      // 简化 Token = 登录时间戳
};
```

### HeartBeatReq（新增）

```tars
// 心跳请求（包含 sessionKey 用于身份验证）
struct HeartBeatReq
{
    0 require long playerId;
    1 require long sessionKey;       // 登录时获取的 sessionKey
};
```

### Lobby.tars 接口

```tars
interface LobbyServant
{
    // 登录
    LoginRsp login(LoginReq req);

    // 注册推送
    int registerPush(long playerId);

    // 心跳（单向调用，无响应参数）
    int heartbeat(HeartBeatReq req);
};
```

### Scene.tars 接口（新增）

```tars
interface SceneServant
{
    // 玩家掉线（标记离线，不改变 AOI 结构）
    int playerOffline(long playerId, int sceneId);

    // 玩家重连（恢复在线状态，不改变 AOI 结构）
    int playerOnline(long playerId, int sceneId);
};
```

### PlayerInfo（新增字段）

```tars
struct PlayerInfo
{
    0 require long playerId;
    1 require string openId;
    2 require string roleName;
    3 require int level;
    4 require float x;
    5 require float y;
    6 require float z;
    7 require int sceneId;
    8 require bool isOnline;     // 是否在线（用于断线重连状态显示）

```
