# V0.4 - 断线重连

> **目标**: 实现完整的断线重连机制，保障玩家体验

## 完成时间
- 预计: 2-3 天

## 架构原则：心跳只在 LobbyServer 管理

```
┌──────────────────────────────────────────────────────────┐
│                     客户端                                │
│                     心跳 ──────────────────────────────────→ LobbyServer
└──────────────────────────────────────────────────────────┘
                                                            │
                         ┌───────────────────────────────────┘
                         ▼
              ┌─────────────────┐
              │  LobbyServer    │
              │  心跳管理        │
              │  • 在线状态      │
              │  • 断线检测      │
              │  • 踢出玩家      │
              └─────────────────┘
                         │
          ┌──────────────┴──────────────┐
          ▼                             ▼
   玩家主动离开                    检测到断线
   leaveScene()                   notifyPlayerOffline()
          │                             │
          ▼                             ▼
┌─────────────────────────────────────────────────────────┐
│                    SceneServer                          │
│  只负责：进入/离开/移动同步                               │
│  不关心心跳！                                           │
└─────────────────────────────────────────────────────────┘
```

## 功能特性

### 核心功能
1. **心跳检测** - LobbyServer 管理客户端心跳
2. **断线检测** - LobbyServer 识别异常断开
3. **状态保存** - 保存玩家离线时的状态
4. **重连恢复** - 恢复玩家游戏状态
5. **数据同步** - 重连后同步期间的变化

### 解决的问题
- 网络波动导致的意外掉线
- 客户端崩溃后的状态恢复
- 移动过程中的断线重连

### Session 管理

```cpp
struct PlayerSession {
    long playerId;           // 玩家ID
    string token;            // 重连令牌
    int sceneId;             // 所在场景
    float x, y, z;           // 断开时的位置
    long disconnectTime;     // 断线时间
    long lastHeartbeat;      // 最后心跳时间（由 LobbyServer 管理）

    // 状态
    bool isOnline;           // 是否在线
    int reconnectCount;      // 重连次数
};
```

### 心跳超时配置

```tars
// 配置文件
HEARTBEAT_INTERVAL = 5000    // 心跳间隔(ms)
HEARTBEAT_TIMEOUT = 30000     // 心跳超时时间(ms)
RECONNECT_WINDOW = 60000      // 重连窗口期(ms)
MAX_RECONNECT_COUNT = 3       // 最大重连次数
```

## 实现步骤

### Step 1: Session 管理模块
```cpp
// SessionManager.h
class SessionManager {
public:
    // 创建 session
    SessionPtr createSession(long playerId);

    // 验证 token
    bool validateToken(long playerId, const string& token);

    // 更新心跳（只在 LobbyServer 调用）
    void updateHeartbeat(long playerId);

    // 检测超时
    void checkTimeout();

    // 清理 session
    void removeSession(long playerId);

private:
    unordered_map<long, SessionPtr> _sessions;
    unordered_map<long, long> _playerLastHeartbeat;
};
```

### Step 2: 心跳机制改造（仅 LobbyServer）
- LobbyServer 完善心跳检测
- 添加超时回调
- 超时后标记为离线但不立即清理
- **SceneServer 不管理心跳**，由 LobbyServer 统一管理

### Step 3: 状态保存
- 进入场景时保存初始状态
- 移动时更新位置
- 断线时保留状态

### Step 4: 重连验证
- 验证 playerId + token
- 检查重连窗口期
- 恢复场景状态

### Step 5: 离线数据同步
- 同步离线期间其他玩家的进出
- 同步离线期间场景变化

## 验收标准

- [ ] 心跳机制正常工作
- [ ] 断线后 30s 内重连成功
- [ ] 重连后位置正确恢复

## 潜在风险

| 风险 | 应对措施 |
|------|----------|
| Session 内存占用 | 定期清理过期 session |
| 重连冲突 | 使用 token 机制防止伪造 |
| 状态不一致 | 重连后全量同步关键数据 |
