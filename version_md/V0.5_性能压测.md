# V0.5 - 性能压测

> **目标**: 实现压测机器人，验证千人在线性能指标

## 完成时间
- 预计: 3-4 天

## 功能特性

### 核心功能
1. **LoadBot** - 压测机器人客户端
2. **登录压测** - 批量登录测试
3. **移动压测** - 批量移动模拟
4. **性能采集** - QPS、延迟统计

### 性能指标目标
| 指标 | 目标值 | 说明 |
|------|--------|------|
| 同时在线 | 1000+ | 千人同服 |
| 登录 QPS | 1000+ | 每秒处理登录数 |
| 移动同步延迟 | < 100ms | P99 |
| 场景切换 QPS | 100+ | 每秒场景切换数 |
| CPU 使用率 | < 80% | 服务端峰值 |

### Bot 行为设计
```cpp
// Bot 状态机
enum class BotState {
    CONNECTING,      // 连接中
    LOGGING_IN,      // 登录中
    CREATING_ROLE,   // 创角中
    IDLE,            // 空闲
    MOVING,          // 移动中
    CHANGING_SCENE,  // 切换场景
    LOGGING_OUT,     // 登出
};

class LoadBot {
public:
    // 初始化(登录并创角/选角)
    bool initialize();
    
    // 主循环
    void update();
    
    // 随机移动
    void randomMove();
    
    // 随机场景切换
    void randomChangeScene();
    
    // 随机登出登入
    void randomLogoutLogin();
    
private:
    BotState _state;
    long _accountId;
    long _roleId;
    tars::CommunicatorPtr _comm;
    ScenePrx _scenePrx;
    
    // 统计
    atomic<int64_t> _moveCount;
    atomic<int64_t> _moveLatencySum;
};
```

### 测试场景

#### 场景1: 登录压力测试
```
1. 同时创建 1000 个 Bot
2. 统计登录成功 QPS
3. 观察服务端 CPU/内存
```

#### 场景2: 移动压力测试
```
1. 1000 个 Bot 同时在线
2. 每个 Bot 每秒发送 1 次移动请求
3. 统计服务端广播消息量
4. 测量移动延迟
```

#### 场景3: 混合压测
```
1. 800 个 Bot 正常移动
2. 200 个 Bot 反复登入登出
3. 统计系统稳定性
```

### 性能采集指标
```cpp
struct PerformanceMetrics {
    // 连接指标
    int totalConnections;
    int activeConnections;
    
    // QPS 指标
    double loginQPS;
    double moveQPS;
    double sceneChangeQPS;
    
    // 延迟指标
    double moveAvgLatency;    // 平均延迟
    double moveP99Latency;    // P99 延迟
    double moveMaxLatency;    // 最大延迟
    
    // 服务端指标
    double cpuUsage;
    double memoryUsage;
    int onlinePlayers;
};
```
